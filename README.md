# Global Estate: Premium Interactive Sales Tool

A world-class, Digideck-inspired interactive sales tool built for high-stakes commercial real estate and brand partnerships. This project transforms a luxury retail website into a cinematic storytelling experience designed to drive leasing, sponsorship, and event bookings.

## 🚀 Vision & Strategy
The core goal of this project is to create an immediate emotional hook for global brands while providing a robust business layer for conversion. It follows a non-linear exploration model, allowing executives to navigate directly to the intelligence or districts most relevant to their mandate.

## ✨ Key Features
- **Cinematic Hero**: Autoplay video backgrounds with parallax motion and bold executive headlines.
- **Interactive Leasing Module**: A dynamic, data-driven slide-out module with footfall intelligence and available unit types.
- **Market Intelligence (Stats)**: Animated data counters with deep contextual storytelling.
- **Non-Linear Navigation**: Floating side navigation and sticky immersive navbar.
- **Video-First UX**: Hover-triggered video previews across all retail and lifestyle districts.
- **Premium Micro-Interactions**: Custom magnetic cursor, smooth scroll transitions, and high-end page loader.

## 🛠 Tech Stack & Architecture
- **Frontend**: Next.js 15, React 19, TypeScript.
- **Animations**: Framer Motion for high-performance, fluid interactions.
- **Styling**: Tailwind CSS for a premium, modular design system.
- **Architecture**: 
  - **Component-Based**: Every section is a self-contained module (e.g., `LeasingModule`, `SideNav`).
  - **Expandable**: Designed for sub-module growth without architectural rewrites.
  - **Performance**: Lazy-loaded assets and optimized video handling (safe play/pause).
